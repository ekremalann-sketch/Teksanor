# Teksanor Ürün Yol Haritası

Bu belge çalışan prototip kapsamını, ticari pilot için gerekenleri ve tam üretim hedeflerini birbirinden ayırır. Tamamlanmamış maddeler canlıda varmış gibi sunulmamalıdır.

## Mevcut durum — çalışan prototip

- [x] Kurumsal tanıtım sitesi ve çözüm sayfaları
- [x] Giriş, oturum ve rol tabanlı portal akışı
- [x] Firma/organizasyon bazlı veri kapsamı
- [x] Proje, departman, çalışan ve iş takibi
- [x] İş emri, saha, ekipman ve bakım akışları
- [x] Finansal kayıt, borç, gider, nakit ve kur görünümü
- [x] Excel ve belge iş akışları
- [x] Denetim/işlem kayıtları
- [x] Cloudflare Pages üretim dağıtımı
- [x] GitHub Actions test ve derleme kapısı

## Aşama 1 — portföy vitrini

- [x] Ürün odaklı README ve canlı demo bağlantısı
- [x] Demo veri ve kapsam uyarıları
- [x] Kurulum, test ve dağıtım açıklaması
- [x] Güvenlik ve katkı politikaları
- [x] Kaynak kod kullanım/lisans sınırı
- [ ] Güncel, anonimleştirilmiş masaüstü ekran görüntüleri
- [ ] Mobil görünüm ekran görüntüleri
- [ ] GitHub About açıklaması, web sitesi ve konu etiketleri
- [ ] GitHub profilinde sabitlenen proje

## Aşama 2 — ücretli pilot öncesi kritik kapılar

- [ ] Demo ve müşteri ortamlarını tamamen ayırma
- [ ] Her firma/rol kombinasyonu için otomatik yetki testleri
- [ ] Rate limiting, hesap kilitleme ve oturum yenileme politikası
- [ ] Dosya türü, boyut ve zararlı içerik kontrolleri
- [ ] D1 ve R2 yedekleme/geri yükleme prosedürü
- [ ] Merkezi hata izleme, çalışma süresi alarmı ve olay günlüğü
- [ ] Bağımlılık, secret ve statik kod güvenlik taraması
- [ ] KVKK veri envanteri, saklama, silme ve aydınlatma süreci
- [ ] Kullanım koşulları ve gizlilik metinleri
- [ ] Pilot müşteriye özel kabul kriterleri ve destek kapsamı

## Aşama 3 — ticari üretim

- [ ] Firma oluşturma ve abonelik yaşam döngüsü
- [ ] Plan/özellik yetkilendirmesi ve ödeme altyapısı
- [ ] E-posta doğrulama, parola sıfırlama ve çok faktörlü doğrulama
- [ ] Gelişmiş raporlama ve dışa aktarma
- [ ] API sürümleme ve entegrasyon anahtarları
- [ ] Veri taşıma, silme ve müşteri ayrılma prosedürü
- [ ] Performans/yük testi ve kapasite hedefleri

## Aşama 4 — ölçekleme seçenekleri

- [ ] Mobil saha deneyimi veya PWA
- [ ] Çevrimdışı iş emri ve senkronizasyon
- [ ] Bildirim ve onay akışları
- [ ] ERP/muhasebe/CRM entegrasyonları
- [ ] Yetki sınırları tanımlanmış yapay zekâ yardımcıları
- [ ] Sektöre özel şablon ve gösterge paketleri

## Ticari karar kuralı

- **Portföy:** Mevcut demo yeterlidir; gerçek veri kullanılmaz.
- **Ücretli pilot:** Aşama 2'nin kritik maddeleri ve müşteri kabul kriterleri tamamlanır.
- **Genel satış/SaaS:** Aşama 3 tamamlanmadan “üretime hazır” iddiası yapılmaz.

Bu ayrım projenin değerini düşürmez; teknik ve ticari olgunluğu doğru yönetildiğini gösterir.
