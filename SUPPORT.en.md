# Support Scope

Teksanor is currently a working product prototype and a controlled-pilot candidate. It is not a generally available commercial service, an accounting product or a promise of uninterrupted availability.

- Non-sensitive bugs and feature proposals: GitHub issue
- Security vulnerabilities: follow [SECURITY.en.md](SECURITY.en.md)
- Commercial licence or pilot enquiry: use the repository owner's public profile contact
- Passwords, tokens and customer data: never post them in issues or comments

Only the current main branch is evaluated. No response-time or service-level guarantee is provided. Real-customer use requires a written scope and a separate acceptance plan.
